SPHERE Shared Education Materials

This website offers a collection of materials for teaching cybersecurity. If you are interested in contributing please make a pull request against this repository.

Filter by tag

Filter by tag

  • BGP Prefix Hijacking

    Introduces inter-domain routing with BGP and the prefix hijacking attacks that threaten it.

  • Binary Analysis An Introduction to Dwarf

    Reviews types of compiled binaries and how debuggers use the debugging information inside them.

  • CCTF Secure Server

    Teams set up and monitor a Web server, defending their own as the Blue team and attacking another's as the Red team.

  • CCTF Secure and Resilient Server

    Teams monitor and defend a Web server against intrusions and DoS attacks while attacking another team's system.

  • Cryptography Symmetric Encryption

    Break a substitution cipher with frequency analysis, then replace it with AES using OpenSSL.

  • DDoS Hash Collisions

    Exploit and mitigate a hash-collision denial-of-service vulnerability.

  • DDoS Slowloris Attack

    Demonstrates the Slowloris attack and analyzes the resources it consumes.

  • DDoS TCP SYN flood

    Launch a TCP SYN flood, observe its effect on legitimate traffic, then apply SYN cookies and repeat the attack.

  • DNS Man-in-the-middle Attacks

    A hands-on demonstration of an attack on the Domain Name System, followed by implementing DNSSEC to mitigate it.

  • DSC Slowloris Attack Detection and Mitigation

    Use online AI tools to analyze Slowloris traffic, diagnose the problem and devise a defense.

  • Exploits Buffer Overflows

    See buffer overflows in source code, exploit them and patch them.

  • Exploits Computer Forensics

    Investigate disk images of three potentially compromised computers to determine what happened to them.

  • Exploits Cross-Site Scripting (XSS)

    Use persistent XSS to steal an administrator's cookie and deface a Web forum, then fix the flaw.

  • Exploits Pathname Attacks

    See pathname attacks in source code, exploit them and patch them.

  • Exploits SQL Injection

    See SQL injection attacks in source code, exploit them and patch them.

  • Intro SPHERE

    A gentle introduction to using SPHERE that works well as a first assignment or in-class demonstration.

  • Intro Unix/Linux

    Practice basic UNIX utilities by finding hidden images from the command line and packaging your answers in a tar ball.

  • Networking IPv6

    Lab exercise incorporating IPv6.

  • Networking Routing, Addressing, Port Forwarding

    Configure IP addressing, route tables, NAT and port forwarding on a small-scale model of the Internet.

  • Passwords Cracking

    Learn how to crack passwords and see how easily it can be done.

  • Prevention OS Hardening

    Start, stop and permanently disable services in Linux to remove unneeded security risks.

  • Prevention POSIX Permissions

    Apply the principle of least privilege with POSIX filesystem permissions, SUID and SGID bits, and sudo.

  • Prevention Setting up IPSec

    Install, configure and test IPSec, intercepting traffic and setting up a tunnel.

  • Prevention Snort

    Use Snort to help secure legacy software in an environment that includes an extremely insecure application.

  • Prevention Stateful Firewalls

    Configure a basic stateful firewall in Linux with iptables, applying the principle of least privilege.

  • Worms Modeling the Spread

    Explore how worms spread under different scanning strategies and how patching can curb them.
